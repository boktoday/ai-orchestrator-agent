# AI Orchestrator Agent

A free Hermes agent profile that teaches one person at a time to orchestrate AI, by building real things with them.

Fifteen lessons, five modules, and an artefact at the end of every lesson. The agent demonstrates first, hands over, then checks your work against what it actually does, not what it sounds like. You finish with a live portfolio you made yourself.

## What Hermes is

Hermes is an open agent harness from Nous Research. The model thinks; the harness gives it hands: a terminal, a file system, a browser, scheduled jobs and memory that survives between sessions. Everything runs on your own machine, so your work stays on your disk and your model key pays for your own usage.

Install guide and documentation: https://hermes-agent.nousresearch.com/docs

The agent in this repository is a Hermes profile: a SOUL, a skill and twelve lessons. Nothing here needs a server, a database or an account beyond your model key.

## What it is not

It is not a video course, a certificate, or a promise about your job. It teaches task-level literacy: what in your work an AI can carry, what it can draft while you check, and what stays human.

## The five modules

1. **Position.** Your work, task by task. The rules you work under. A 90 day plan.
2. **Language and skills.** The words that get work done, from the 400-term agent glossary. What a skill is and when it fires. Write your own skill for a task you repeat.
3. **Build.** A mini app. An agent that does a chore. A portfolio.
4. **Connect and automate.** What an API is. Webhooks and connected tools. What a cronjob is.
5. **Guardrails.** Verify before you trust. Failure drills. Ship and tell.

## Who it is for

School leavers, graduates, career changers and solo operators who want to be the person who can direct AI, not the person replaced by it.

## Install

See [INSTALL.md](INSTALL.md). One Hermes install, one folder copy, your own model key. Free.

The agent is free and always will be. The only paid thing is a Saturday live build with human review of your portfolio, run by Brendan. The agent mentions it once, in the last lesson, and never pushes. Nothing in the course depends on it.
