# Working on this repo

This repository is a Hermes agent profile, not an application. The agent is the product; the lessons are its syllabus.

- `SOUL.md` is the coach's identity and rules. Change it with care: the refusal to pass unverified work is the course's integrity.
- `skills/orchestrator-course/SKILL.md` is the runtime: how to read progress, run a lesson, seal it.
- `skills/orchestrator-course/references/lesson-01.md` to `lesson-12.md` are the lessons themselves.
- `scripts/start_course.py` creates the student's work folder.
- `docs/method.md` explains why the lessons are shaped this way.

Rules for editing lessons: keep one artefact per lesson, keep the demo before the handover, and never add a lesson that cannot be checked.
